# 文种速查表

> 常用文字快速对照表。写作时按用途定位文种，查看结构和要点。

## 文种选择

| 你想…… | 选这个文种 | 结构 | 篇幅 |
|---------|-----------|------|------|
| 向院领导汇报工作 | **工作汇报** | 背景→做法→成效→问题→打算 | 500-3000字 |
| 请求批准事项 | **请示** | 依据→事项→建议→结语 | 300-800字 |
| 向上级报告情况 | **报告** | 依据→情况→结论 | 500-2000字 |
| 就某事项作出说明 | **情况说明** | 事由→情况→处理→意见 | 300-1500字 |
| 记载会议决定 | **会议纪要** | 会议信息→议题→议定事项 | 500-2000字 |
| 报送工作动态 | **信息简报** | 导语→做法→效果 | 500-1000字 |
| 领导在会议讲话 | **领导讲话稿** | 开场→主体→号召 | 800-5000字 |
| 平级单位商洽工作 | **函** | 背景→事项→恳请→结语 | 200-600字 |
| 传达事项、部署工作 | **通知** | 事项→办理要求→时限/反馈（适用时） | 按事项确定 |
| 分析业务数据和运行态势 | **质效分析** | 口径→数据→变化→问题→改进方向 | 按材料确定 |
| 整理类案或个案材料 | **案件分析材料** | 基本情况→争议观点/特点→待核实问题 | 1000-3000字 |

> 提示函使用函件规则；完整版/简版属于模板变体，不是独立文种。以上篇幅均为参考值。

## 核心禁区

| 规则 | 说明 |
|------|------|
| **一文一事** | 一个请示只能请求一件事 |
| **报告不夹带请示** | 如需请示，另拟请示件 |
| **不得编造** | 无依据的内容用【待补充】标注 |
| **脱敏处理** | 当事人→某某，案号→某号 |
| **个案判断有边界** | 不独立作出案件结论或办案建议；可整理用户提供的观点，或润色已审定意见 |

## 结语对照

| 文种 | 结语 |
|------|------|
| 工作汇报 | "特此汇报"或自然收束 |
| 请示 | "妥否，请批示" |
| 报告 | "特此报告" |
| 情况说明 | "特此说明" |
| 函（去函） | "特此函告" / "请予函复" |
| 函（复函） | "此复" |
| 通知 | "特此通知" |
| 信息简报 | 自然收束 |
| 质效分析 | 通常自然收束，按用途确定 |

# 文种速查表

> 常用文字快速对照表。写作时按用途定位文种，查看结构和要点。

## 文种选择

| 你想…… | 选这个文种 | 结构 | 篇幅 |
|---------|-----------|------|------|
| 向院领导汇报工作 | **工作汇报** | 背景→做法→成效→问题→打算 | 500-3000字 |
| 请求批准事项 | **请示** | 依据→事项→建议→结语 | 300-800字 |
| 向上级报告情况 | **报告** | 依据→情况→结论 | 500-2000字 |
| 就某事项作出说明 | **情况说明** | 事由→情况→处理→意见 | 300-1500字 |
| 记载会议决定 | **会议纪要** | 会议信息→议题→议定事项 | 500-2000字 |
| 报送工作动态 | **信息简报** | 导语→做法→效果 | 500-1000字 |
| 领导在会议讲话 | **领导讲话稿** | 开场→主体→号召 | 800-5000字 |
| 平级单位商洽工作 | **函** | 背景→事项→恳请→结语 | 200-600字 |
| 综合分析案件 | **案件分析材料** | 案情→焦点→分析→建议 | 1000-3000字 |

## 核心禁区

| 规则 | 说明 |
|------|------|
| **一文一事** | 一个请示只能请求一件事 |
| **报告不夹带请示** | 如需请示，另拟请示件 |
| **不得编造** | 无依据的内容用【待补充】标注 |
| **脱敏处理** | 当事人→某某，案号→某号 |
| **不代替承办人结论** | 不写"经审查认为" |

## 结语对照

| 文种 | 结语 |
|------|------|
| 工作汇报 | "特此汇报"或自然收束 |
| 请示 | "妥否，请批示" |
| 报告 | "特此报告" |
| 情况说明 | "特此说明" |
| 函（去函） | "特此函告" / "请予函复" |
| 函（复函） | "此复" |
| 通知 | "特此通知" |
| 信息简报 | 自然收束 |

# 快速入门指南

> 面向新用户的 3 分钟上手教程。如果你是第一次使用本 Skill，请从本文开始。

## 三步上手

### 第一步：激活 Skill

在已安装该 Skill 的 Agent 中提出以下任一类请求即可触发（具体发现与加载行为取决于宿主平台）：

> "帮我写一份第三检察部2025年上半年经济犯罪检察工作汇报"
> "起草一份关于追加办案经费的请示"
> "润色一下这份情况说明"

### 第二步：与 Skill 对话

说明文种、用途和已有材料即可。材料中有敏感身份信息或可能涉密内容时，请先确认使用环境获准处理，或先提供脱敏版本。对简单明确、材料充分的任务，Skill 会直接起草；只有缺少会影响实质内容的信息时才提问。

```
明确简单的任务 → 直接成稿 + 适用项核查摘要
复杂/多义任务或你要求先确认 → 先出提纲，确认后再成稿
仅要求润色/审阅/某一部分 → 只交付该项
```

### 第三步：拿到成果

交付内容按你的请求选择，通常包括：

| 部分 | 内容 | 用途 |
|------|------|------|
| 正式稿/指定内容 | 按你的文种和要求生成；缺失信息用占位符标注 | 审阅和修改 |
| 核查摘要 | 需要时只列实际检查过的内容及需来源/人工确认的事项 | 方便复核 |
| 写作提纲 | 复杂任务或你明确要求时提供 | 先确认结构 |

## 常见问题

**Q: 我只有初稿，需要润色怎么办？**
A: 直接把草稿发给 Skill，并说明是润色还是实质修改。Skill 会保留事实和立场；只有你要求或复杂任务需要时才先出提纲。

**Q: 数据不全怎么办？**
A: Skill 不会编造数据。缺失内容用具体占位符标注，并在需要时列出待补事项。

**Q: 哪些事 Skill 不能做？**
A: 不独立作个案法律判断或办案决定，不编造法律依据，不模仿特定个人风格，也不在未获授权的环境中处理涉密材料。详见 `references/风险规则.md`。

## 参考文件优先级

| 文件类型 | 优先级 |
|----------|--------|
| 当前任务明确指定且适用的制度/样稿 | 用于确定本任务的格式与文风；与其他来源冲突时指出差异 |
| `-用户提供版.md` 文件 | 本部门补充参考；不因文件名自动高于现行制度或风险规则 |
| `references/风险规则.md` | 唯一风险规则编号来源，始终适用 |

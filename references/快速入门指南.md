# 快速入门指南

> 面向新用户的 3 分钟上手教程。如果你是第一次使用本 Skill，请从本文开始。

## 三步上手

### 第一步：激活 Skill

在 Claude Code 中说出以下任意一句话即可激活：

> "帮我写一份第三检察部2025年上半年经济犯罪检察工作汇报"
> "起草一份关于追加办案经费的请示"
> "润色一下这份情况说明"

### 第二步：与 Skill 对话

激活后，Skill 会引导你经历以下流程：

```
你描述需求
  → Skill 确认文种和细节（决策树）
  → （无草稿时）出提纲让你确认
  → 生成正文 + 自查清单
  → 输出三件套
```

### 第三步：拿到成果

每次输出包含三部分：

| 部分 | 内容 | 用途 |
|------|------|------|
| 写作提纲 | 标题建议 + 框架 + 要点 | 快速确认方向 |
| 正式稿 | 完整正文，占位符标注【待补充】 | 可直接使用或修改 |
| 自查清单 | 逐项核查，列出待办项 | 确保质量 |

## 常见问题

**Q: 我只有初稿，需要润色怎么办？**
A: 直接把草稿发给 Skill，它会跳过提纲生成，直接润色后输出正式稿 + 自查清单。

**Q: 数据不全怎么办？**
A: Skill 不会编造任何数据。缺失内容用【待补充】标注，在自查清单中列出待办项。

**Q: 哪些事 Skill 不能做？**
A: 不代替检察官下案件结论、不编造法律依据、不模仿特定领导语气、不泄露涉密信息。详见 SKILL.md 中的「风险边界 R1-R9」。

## 输出格式

仅在有助于复核时附核查摘要。默认列出适用的关键项和待办事项，不输出整套清单，也不把模型自查表述为正式审查结论。状态应区分文本内检查、来源核实、人工确认和不适用。用户要求详细清单时，只列当前任务适用的项目。

```
核查摘要示例：

- 文本内已检查：标题与文种匹配、层次序号一致、材料内数据前后一致。
- 需来源核实：业务数据来源、法律依据的现行版本。
- 需人工确认：脱敏是否符合本单位要求、发文对象和签批流程。
- 不适用：页码、版记（本次仅交付纯文本）。
```

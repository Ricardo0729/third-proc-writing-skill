# Agent 元数据与兼容性说明

本仓库以 Agent Skill 的 `SKILL.md` 为通用入口。技能名和描述用于识别技能；`metadata.version` 与 `metadata.category` 是本仓库维护信息，不保证每个平台都会展示或解释。

## 模型与平台行为

- 不在通用技能元数据中固定模型名称。模型选择、工具调用、隐式触发、参考文件加载和敏感数据处理方式均由宿主 Agent 决定。
- 不根据安装成功推断技能已完整生效。安装后应在目标平台确认技能可被发现、正文可加载、相对路径下的参考文件可访问。
- 面向具体 Agent 的安装命令和配置应放在平台专属说明中，并记录适用版本与最近验证日期；平台更新后重新核验。

## 兼容性核对项

发布或更新时，逐个平台确认：

1. 技能目录与 `SKILL.md` 文件名符合平台要求。
2. YAML frontmatter 能被平台解析；未知字段不会导致整个技能加载失败。
3. 相对路径引用的 `references/` 和 `templates/` 文件可以读取。
4. 隐式触发描述覆盖目标用户的真实请求，同时避免将一般法律咨询误路由到写作技能。
5. 涉及附件和敏感材料时，技能不会自动解包、全量读取或写回仓库。
